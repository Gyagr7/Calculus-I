    Section 4.5 The Substitution Rule

    Today’s Question.

    Can a complicated integral hide a familiar derivative?
    🔗
    🔗
    Every integral in this section is a puzzle with the same shape. Somewhere inside it, the Chain Rule has already happened. Our job is to spot it and run it backward.
    🔗

    Subsection 4.5.1 Before anything new: what are we looking for?

    Compare these two questions:
    \begin{equation*} \text{A. } \int 3x^2\,dx \qquad\qquad \text{B. } \int_0^2 3x^2\,dx. \end{equation*}
    🔗

    Checkpoint 4.5.1. What kind of answer?

    Which question asks for a fixed number?
    🔗
    • A
    • Not quite. A has no bounds, so it asks for every antiderivative of \(3x^2\text{.}\) That is a family of functions.
    • B
    • Yes. Fixed bounds, fixed number.
    🔗
    The most general antiderivative of \(3x^2\) is \(x^3 + C\text{.}\) So question A has the answer \(x^3 + C\text{.}\)
    🔗

    Checkpoint 4.5.2. Now question B.

    🔗
    Why does A need \(+C\) but B does not? Every vertical shift of \(x^3\) has the same derivative, so \(C\) describes the whole family. In B, the same \(C\) shows up at both endpoints and cancels.
    🔗

    Two kinds of answers.

    An indefinite integral describes a family of antiderivatives. A definite integral with fixed bounds gives a number.
    🔗
    🔗
    Either way, the hard part is the same: finding an antiderivative. That is what today’s new technique helps with.
    🔗

    Checkpoint 4.5.3. Quick check.

    (a) Find \(\int (4x^3 + 2)\,dx\text{.}\) (b) Evaluate \(\int_0^1 (4x^3 + 2)\,dx\text{.}\) Before you compute, say what kind of answer each one should be.
    🔗
    Solution.
    (a) A family of functions: \(x^4 + 2x + C\text{.}\) (b) A number: \(\left[x^4 + 2x\right]_0^1 = 1 + 2 = 3\text{.}\)
    🔗
    🔗
    🔗
    🔗

    Subsection 4.5.2 When the antiderivative is harder to see

    Consider
    \begin{equation*} \int 2x(x^2 + 1)^3\,dx. \end{equation*}
    First idea: expand, then integrate term by term. Since \((x^2 + 1)^3 = x^6 + 3x^4 + 3x^2 + 1\text{,}\)
    \begin{equation*} 2x(x^2 + 1)^3 = 2x^7 + 6x^5 + 6x^3 + 2x, \end{equation*}
    and that integrates to \(\tfrac14 x^8 + x^6 + \tfrac32 x^4 + x^2 + C\text{.}\) That works. Expanding is a perfectly valid method.
    🔗
    Now imagine the problem were
    \begin{equation*} \int 2x(x^2 + 1)^{100}\,dx. \end{equation*}
    Expanding is still possible. It would give you \(101\) terms before you even multiply by \(2x\text{.}\) No thanks.
    🔗

    The real question.

    Can we use the structure of the expression to find an antiderivative, without expanding everything?
    🔗
    🔗
    🔗

    Subsection 4.5.3 Try a guess. Differentiate it. Adjust it.

    Back to \(\int 2x(x^2 + 1)^3\,dx\text{.}\) The integrand has a third power in it. Antiderivatives raise the power by one, so try the guess
    \begin{equation*} H(x) = (x^2 + 1)^4. \end{equation*}
    Differentiate it with the Chain Rule:
    \begin{equation*} H'(x) = 4(x^2 + 1)^3 \cdot 2x = 8x(x^2 + 1)^3. \end{equation*}
    🔗

    Checkpoint 4.5.4. What matched?

    Compare \(H'(x) = 8x(x^2 + 1)^3\) with the integrand \(2x(x^2 + 1)^3\text{.}\) What matches, and what is off?
    🔗
    Solution.
    The inside expression \(x^2 + 1\text{,}\) its third power, and the factor \(x\) all match. The only problem is a constant: \(H'\) is \(4\) times too big.
    🔗
    🔗
    🔗
    A constant is easy to fix. Divide the guess by \(4\text{:}\)
    \begin{equation*} F(x) = \frac14 (x^2 + 1)^4. \end{equation*}
    Check: \(F'(x) = \frac14 \cdot 4(x^2 + 1)^3 \cdot 2x = 2x(x^2 + 1)^3\text{.}\) Exactly right. So
    \begin{equation*} \int 2x(x^2 + 1)^3\,dx = \frac14 (x^2 + 1)^4 + C. \end{equation*}
    🔗

    Checkpoint 4.5.5. Try one.

    Use the same guess-differentiate-adjust idea on \(\int 2x(x^2 + 1)^{100}\,dx\text{.}\)
    🔗
    Solution.
    Guess \((x^2 + 1)^{101}\text{.}\) Its derivative is \(101(x^2 + 1)^{100} \cdot 2x\text{,}\) which is \(101\) times too big. So \(\int 2x(x^2 + 1)^{100}\,dx = \frac{1}{101}(x^2 + 1)^{101} + C\text{.}\) No expanding needed.
    🔗
    🔗
    🔗
    Notice something. The expanded answer from before and the compact answer \(\frac14(x^2+1)^4 + C\) look different. They differ by a constant, so they describe the same family.
    🔗

    What just happened.

    We used a rule we already knew: the Chain Rule. This time, we ran it backward.
    🔗
    🔗
    🔗

    Subsection 4.5.4 Same puzzle, one small change

    Now try \(\int 3x(x^2 + 1)^3\,dx\text{.}\) Changing \(2x\) to \(3x\) does not change the inside expression. It is still \(x^2 + 1\text{.}\) Only the constant out front changed, and
    \begin{equation*} 3x = \frac32 (2x). \end{equation*}
    🔗

    Checkpoint 4.5.6. Use the last puzzle.

    🔗
    🔗

    Subsection 4.5.5 Find the clue: an inside expression and its derivative

    Checkpoint 4.5.7. Fill in the derivative column.

    Find the derivative of each inside expression: \(x^2 + 1\text{,}\) \(\;3x^2 + 2\text{,}\) \(\;5x\text{,}\) \(\;\sin x\text{.}\)
    🔗
    Solution.
    Inside expression Its derivative
    \(x^2 + 1\) \(2x\)
    \(3x^2 + 2\) \(6x\)
    \(5x\) \(5\)
    \(\sin x\) \(\cos x\)
    🔗
    🔗

    Checkpoint 4.5.8. Spot the pair.

    In each integral, find an inside expression and a factor that matches its derivative, possibly up to a constant. (a) \(\int 6x(3x^2 + 2)^4\,dx\) (b) \(\int e^{5x}\,dx\) (c) \(\int \cos x\,(\sin x)^3\,dx\)
    🔗
    Solution.
    (a) Inside: \(3x^2 + 2\text{.}\) Matching factor: \(6x\text{.}\) (b) Inside: \(5x\text{.}\) Its derivative is the constant \(5\text{,}\) which is not there. Since \(\frac{d}{dx}e^{5x} = 5e^{5x}\text{,}\) adjust with a factor of \(\frac15\text{.}\) (c) Inside: \(\sin x\text{.}\) Matching factor: \(\cos x\text{.}\)
    🔗
    🔗
    🔗

    Checkpoint 4.5.9. A useful contrast.

    Does the same simple guess work for \(\int (x^2 + 1)^3\,dx\text{?}\) (Differentiate \(\frac14(x^2 + 1)^4\) and compare.)
    🔗
    • Yes, adjust by a constant
    • Differentiate it: you get \(2x(x^2+1)^3\text{.}\) The extra factor is \(2x\text{,}\) which is a variable. No constant can cancel it.
    • No, the matching derivative is missing
    • Right. The extra factor \(2x\) is a variable, so a constant adjustment cannot remove it. This integral is still doable by expanding: \(\frac17x^7 + \frac35x^5 + x^3 + x + C\text{.}\)
    🔗

    Look for the pair.

    An inside expression, and its derivative. A constant mismatch can be adjusted. A variable mismatch cannot.
    🔗
    🔗
    🔗

    Subsection 4.5.6 Give the inside expression a shorter name

    We have already solved \(\int 2x(x^2 + 1)^3\,dx\text{.}\) Now let us organize the same reasoning. Call the inside expression \(u\text{:}\)
    \begin{equation*} u = x^2 + 1. \end{equation*}
    Then \(\frac{du}{dx} = 2x\text{,}\) and we write
    \begin{equation*} du = 2x\,dx. \end{equation*}
    The notation \(du = 2x\,dx\) records the derivative of our inside expression. It tells us how to replace the matching factor together with \(dx\text{:}\)
    \begin{equation*} \int \underbrace{(x^2 + 1)^3}_{u^3}\,\underbrace{2x\,dx}_{du} = \int u^3\,du = \frac14 u^4 + C. \end{equation*}
    Our question was about \(x\text{,}\) so put \(u = x^2 + 1\) back:
    \begin{equation*} \int 2x(x^2 + 1)^3\,dx = \frac14(x^2 + 1)^4 + C. \end{equation*}
    Same answer as before. This way of rewriting an integral is called substitution, or \(u\)-substitution.
    🔗

    Checkpoint 4.5.10. What does \(du\) replace?

    In the rewrite above, the single symbol \(du\) replaces what?
    🔗
    • Just \(dx\)
    • Not quite. If \(du\) only replaced \(dx\text{,}\) the \(2x\) would still be hanging around.
    • Just \(2x\)
    • Close. But the \(dx\) goes with it.
    • The whole piece \(2x\,dx\)
    • Yes. \(du\) swallows the whole piece.
    🔗
    🔗

    Subsection 4.5.7 Why does it work?

    If \(F'(u) = f(u)\text{,}\) the Chain Rule says
    \begin{equation*} \frac{d}{dx}\bigl[F(g(x))\bigr] = f(g(x))\,g'(x). \end{equation*}
    Read it backward:
    \begin{equation*} \int f(g(x))\,g'(x)\,dx = F(g(x)) + C. \end{equation*}
    Writing \(u = g(x)\) and \(du = g'(x)\,dx\) makes the familiar integral visible.
    🔗

    Fact 4.5.11. The Substitution Rule.

    If \(u = g(x)\) is differentiable and \(f\) is continuous on the range of \(g\text{,}\) then
    \begin{equation*} \int f(g(x))\,g'(x)\,dx = \int f(u)\,du. \end{equation*}
    🔗
    🔗

    Remember.

    Substitution organizes the reverse Chain Rule. The name \(u\) helps us see a familiar integral inside a complicated one.
    🔗
    🔗
    🔗

    Subsection 4.5.8 We do: account for the constant

    Evaluate \(\int x(3x^2 + 2)^4\,dx\text{.}\)
    1. Choose. \(u = 3x^2 + 2\text{,}\) so \(du = 6x\,dx\text{.}\)
      🔗
      🔗
    2. Match. The integral has \(x\,dx\text{,}\) not \(6x\,dx\text{.}\) So \(x\,dx = \frac16\,du\text{.}\)
      🔗
      🔗
    3. Rewrite everything in \(u\text{.}\) \(\int x(3x^2 + 2)^4\,dx = \frac16\int u^4\,du\text{.}\)
      🔗
      🔗
    4. Integrate and go back. \(\frac16 \cdot \frac{u^5}{5} + C = \frac{1}{30}(3x^2 + 2)^5 + C\text{.}\)
      🔗
      🔗
    Check by differentiating: \(\frac{1}{30}\cdot 5(3x^2 + 2)^4 \cdot 6x = x(3x^2 + 2)^4\text{.}\)
    🔗
    🔗

    Subsection 4.5.9 You do: make the familiar integral visible

    For each puzzle: choose \(u\text{,}\) find \(du\) and account for any constant, rewrite the entire integral in \(u\text{,}\) integrate, substitute back, and check by differentiating.
    🔗

    Checkpoint 4.5.12. Puzzle A.

    \(\int 6x(3x^2 + 2)^4\,dx\)
    🔗
    Solution.
    \(u = 3x^2 + 2\text{,}\) \(du = 6x\,dx\text{.}\) No adjustment needed this time: \(\int u^4\,du = \frac15 u^5 + C = \frac15(3x^2 + 2)^5 + C\text{.}\) Compare with the We Do problem: there the factor was \(x\text{,}\) so the coefficient was \(\frac{1}{30}\) instead of \(\frac15\text{.}\)
    🔗
    🔗
    🔗

    Checkpoint 4.5.13. Puzzle B.

    \(\int e^{5x}\,dx\)
    🔗
    Solution.
    \(u = 5x\text{,}\) \(du = 5\,dx\text{,}\) so \(dx = \frac15\,du\text{.}\) \(\frac15\int e^u\,du = \frac15 e^{5x} + C\text{.}\) Check: \(\frac15 e^{5x}\cdot 5 = e^{5x}\text{.}\)
    🔗
    🔗
    🔗

    Checkpoint 4.5.14. Puzzle C.

    \(\int \cos x\,(\sin x)^3\,dx\)
    🔗
    Solution.
    \(u = \sin x\text{,}\) \(du = \cos x\,dx\text{.}\) \(\int u^3\,du = \frac14 u^4 + C = \frac14\sin^4 x + C\text{.}\) Check: \(\frac14 \cdot 4\sin^3 x\cos x = \cos x\,(\sin x)^3\text{.}\)
    🔗
    🔗
    🔗

    Check the puzzle pieces.

    After rewriting, the integral should use one variable throughout. After integrating, differentiate your answer to check it.
    🔗
    🔗
    🔗

    Subsection 4.5.10 Same antiderivative, different kind of answer

    Compare \(\int 2x(x^2 + 1)^3\,dx\) and \(\int_0^1 2x(x^2 + 1)^3\,dx\text{.}\) The first is a family. The second is a number. There are two routes to that number.
    🔗

    Route A: go back to \(x\text{,}\) then evaluate.

    We already have the antiderivative \(F(x) = \frac14(x^2 + 1)^4\text{.}\) Use the original \(x\)-bounds:
    \begin{equation*} \int_0^1 2x(x^2 + 1)^3\,dx = \left[\frac14(x^2 + 1)^4\right]_0^1 = \frac14(16 - 1) = \frac{15}{4}. \end{equation*}
    No \(+C\text{:}\) it would appear at both endpoints and cancel.
    🔗
    🔗

    Route B: stay in \(u\).

    Let \(u = x^2 + 1\text{,}\) \(du = 2x\,dx\text{.}\) The old bounds \(0\) and \(1\) are values of \(x\text{.}\) What are the matching values of \(u\text{?}\)
    🔗
    🔗

    Checkpoint 4.5.15. Translate the endpoints.

    🔗
    So
    \begin{equation*} \int_0^1 2x(x^2 + 1)^3\,dx = \int_1^2 u^3\,du = \left[\frac14 u^4\right]_1^2 = \frac14(16 - 1) = \frac{15}{4}. \end{equation*}
    Same answer. Both routes compute the same accumulation.
    🔗

    Keep the variable and its bounds together.

    An expression in \(x\) uses \(x\)-bounds. An expression in \(u\) uses the matching \(u\)-bounds.
    🔗
    🔗

    Checkpoint 4.5.16. Your turn.

    🔗
    🔗

    Subsection 4.5.11 Find the bug and fix it

    Checkpoint 4.5.17. Bug A: an adjustment is missing.

    A student writes \(\int x(x^2 + 1)^3\,dx = \frac14(x^2 + 1)^4 + C\text{.}\) Differentiate the answer. What is wrong? Fix it.
    🔗
    Solution.
    \(\frac{d}{dx}\left[\frac14(x^2 + 1)^4\right] = 2x(x^2 + 1)^3\text{,}\) which is twice the integrand. With \(u = x^2 + 1\) we need \(x\,dx = \frac12\,du\text{,}\) so \(\int x(x^2 + 1)^3\,dx = \frac12\int u^3\,du = \frac18(x^2 + 1)^4 + C\text{.}\)
    🔗
    🔗
    🔗

    Checkpoint 4.5.18. Bug B: the variable changed, but the bounds did not.

    A student sets \(u = x^2 + 1\) and writes \(\int_0^1 2x(x^2 + 1)^3\,dx = \int_0^1 u^3\,du\text{.}\) What went wrong?
    🔗
    Solution.
    The bounds \(0\) and \(1\) are \(x\)-values. They match \(u = 1\) and \(u = 2\text{.}\) Correct version: \(\int_1^2 u^3\,du\text{.}\)
    🔗
    🔗
    🔗

    Checkpoint 4.5.19. Bug C: only part of the integral was rewritten.

    A student sets \(u = x^2 + 1\text{,}\) finds \(du = 2x\,dx\text{,}\) and writes \(\int 2x(x^2 + 1)^3\,dx = \int 2x\,u^3\,du\text{.}\) What is the problem?
    🔗
    • The \(2x\) was counted twice
    • Yes. \(du\) already replaced the whole piece \(2x\,dx\text{.}\) The correct rewrite is \(\int u^3\,du\text{.}\)
    • Nothing. It is fine to leave some \(x\) in
    • Not here. An integral in \(u\) with an \(x\) still inside cannot be integrated with respect to \(u\text{.}\) And this \(2x\) has already been used up by \(du\text{.}\)
    • The student should have chosen \(u = 2x\)
    • \(u = x^2 + 1\) is a fine choice. The issue is what happened to \(2x\text{.}\)
    🔗
    🔗

    Subsection 4.5.12 More substitution puzzles

    Find the pair before you integrate.

    For each one, name \(u\) and \(du\) only. No integrating yet.
    🔗
    🔗

    Checkpoint 4.5.20.

    (a) \(\int x^2(x^3 + 2)^4\,dx\) (b) \(\int \frac{(\ln x)^2}{x}\,dx\text{,}\) \(x \gt 0\) (c) \(\int \frac{\sin x}{2 + \cos x}\,dx\)
    🔗
    Solution.
    (a) \(u = x^3 + 2\text{,}\) \(du = 3x^2\,dx\text{,}\) so \(x^2\,dx = \frac13\,du\text{.}\) (b) \(u = \ln x\text{,}\) \(du = \frac1x\,dx\text{.}\) (c) \(u = 2 + \cos x\text{,}\) \(du = -\sin x\,dx\text{,}\) so \(\sin x\,dx = -du\text{.}\) Watch the constant and the sign.
    🔗
    🔗
    🔗

    Solve, then check.

    Integrate. Then differentiate your answer to check it.
    🔗
    🔗

    Checkpoint 4.5.21.

    \(\int (2x - 3)^6\,dx\)
    🔗
    Solution.
    \(u = 2x - 3\text{,}\) \(du = 2\,dx\text{.}\) \(\frac12\int u^6\,du = \frac{(2x - 3)^7}{14} + C\text{.}\)
    🔗
    🔗

    Checkpoint 4.5.22.

    Checkpoint 4.5.25. One piece is still in \(x\).

    Evaluate \(\int x\sqrt{x + 3}\,dx\text{.}\) Hint: with \(u = x + 3\text{,}\) there is a leftover \(x\text{.}\) Can you write it in terms of \(u\) too?
    🔗
    Solution.
    \(u = x + 3\text{,}\) \(du = dx\text{,}\) and \(x = u - 3\text{.}\) So \(\int (u - 3)u^{1/2}\,du = \int \left(u^{3/2} - 3u^{1/2}\right)du = \frac25(x + 3)^{5/2} - 2(x + 3)^{3/2} + C\text{.}\) A leftover \(x\) does not mean the substitution failed. It means one more piece needs rewriting.

    Definite integrals: keep the variable and bounds together.

    With \(u = \ln x\) on \(1 \le x \le e\text{,}\) the \(u\)-bounds are \(0\) and \(1\text{.}\) With \(u = \cos x\) on \(0 \le x \le \frac{\pi}{2}\text{,}\) the \(u\)-bounds go from \(1\) down to \(0\text{.}\) Keep them in that order. Do not swap them just to put the smaller number on the bottom.

    Checkpoint 4.5.28. Find the bug by differentiating.

    A student claims \(\int e^{-3x}\,dx = -3e^{-3x} + C\text{.}\) Check it.

    Checkpoint 4.5.30.

    In one sentence: why is substitution connected to the Chain Rule?
    🔗
    Solution.
    The Chain Rule produces an outer derivative times an inner derivative. Substitution recognizes that pattern and runs it backward.
